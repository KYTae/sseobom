증명사진 만들기

휴대폰으로 찍은 사진을 여권·주민등록증·이력서 규격의 증명사진으로 만들어요. AI가 배경을 지우고 흰색·하늘색 배경으로 바꾸며, 머리 길이와 위 여백을 규격 안내선에 맞춰 자동으로 배치해요. 300·600dpi 파일로 저장하거나 4×6·A4 인화지에 여러 장 배열한 인쇄용 시트로도 받아요. 사진은 서버에 올라가지 않고 이 브라우저 안에서만 처리돼요.

기본
사진 올리기정면을 보고 찍은 사진을 끌어다 놓거나 눌러서 골라요. 배경이 단순하고 머리 위와 어깨까지 여유 있게 나온 사진이 가장 좋아요. 올리면 규격 틀 안에 사진이 놓여요.
규격여권·주민등록증·운전면허(3.5×4.5cm), 반명함(3×4cm), 명함판(5×7cm), 미국 비자(2×2인치), 중국·일본 비자 등을 고르면 크기와 머리 길이·위 여백 기준이 함께 바뀌어요. 직접 입력으로 원하는 mm 크기도 돼요.
배경AI 배경 제거를 고르고 배경 지우기를 누르면 인물만 남기고 흰색·연회색·하늘색이나 직접 고른 색으로 배경을 채워요. 최고 품질은 머리카락까지 정교하지만 처음 한 번 약 88MB 모델을 내려받고(그래픽 카드가 있으면 1초 안팎), 빠름은 2.3MB로 몇 초면 끝나요. 원본 배경 그대로는 배경을 바꾸지 않고 크기만 맞춰요.
얼굴 맞춤 · 보정
자동 맞춤배경을 지우면 머리 위와 턱 위치를 찾아 규격의 머리 길이·위 여백에 맞게 자동으로 놓아요. 안내선의 초록 띠 안에 머리 위(정수리)와 턱이 들어가면 규격에 맞아요. 아쉬우면 사진을 끌어 옮기고 휠·슬라이더로 크기를 바꾸세요.
아래 채우기사진이 어깨에서 잘려 틀 아래가 비면, 마지막 줄을 늘려 자연스럽게 채워요. 어색하면 끄고 사진을 조금 작게 하세요.
보정밝기·대비·채도를 살짝 조절해요. 과하면 심사에서 문제가 될 수 있으니 자연스러운 범위로 두세요. 얼굴 형태를 바꾸는 보정은 하지 않아요.
저장 · 한계
저장JPG·PNG로 한 장을 저장하면 파일에 300 또는 600dpi 정보가 들어가 인쇄·온라인 제출 규격(예: 3.5×4.5cm·300dpi = 413×531픽셀)에 맞아요. 인쇄 시트는 4×6인치 인화지나 A4에 자를 선과 함께 여러 장을 배열해요.
한계 · 정직한 안내머리 위·턱 찾기는 배경을 지운 결과로 어림하는 방식이라 모자·긴 머리·기울어진 얼굴에서는 틀릴 수 있어요 — 안내선을 보고 직접 맞춰 주세요. 규격의 세부 기준(표정·안경·귀 노출 등)은 기관마다 달라 이 도구가 대신 판단하지 않아요. 아주 큰 사진은 긴 변 3,000px로 줄여서 작업해요(600dpi 명함판까지 확대 없이 충분한 크기예요). 얼굴이 작게 찍힌 사진은 결과가 확대돼 흐릿할 수 있어 미리 알려 드려요.
