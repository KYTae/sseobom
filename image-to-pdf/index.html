이미지 올리기 · 상단 버튼
드롭존이미지를 끌어다 놓거나 눌러서 파일 선택 창을 열어요. 여러 장을 한 번에 고를 수 있고, 이미 올린 목록에 계속 더할 수도 있어요. JPG·PNG·WebP·AVIF·GIF·BMP를 올릴 수 있고, 움직이는 GIF는 첫 장면만 들어가요.
전체 지우기올린 이미지를 모두 지우고 처음 화면으로 되돌려요.
화질 (고화질 / 용량 최적화)고화질은 원본 해상도를 그대로 유지해요(JPG 사진은 조건이 맞으면 원본 파일을 손대지 않고 그대로 넣고, PNG·BMP처럼 무손실 이미지는 무손실로 넣어요). 사진이 여러 장이면 결과가 100MB를 넘을 수 있어 미리 알려드려요. 용량 최적화는 페이지 크기에 맞는 해상도(150dpi)로 줄이고 JPG로 압축해서, 같은 사진 12장이 약 4분의 1 크기가 돼요. 투명한 부분이 있는 이미지는 투명을 잃지 않도록 그대로 둬요.
페이지 (이미지 크기 / A4)이미지 크기는 이미지 비율 그대로 페이지를 만들어요(지금까지의 방식). A4는 모든 페이지를 A4로 통일하고 이미지를 여백 안에 가운데로 넣어서, 여러 장을 인쇄할 때 크기가 들쭉날쭉하지 않아요. A4보다 작은 이미지는 억지로 늘려 흐려지지 않게 원래 크기로 놓아요.
모드 (하나로 합치기 / 각각 PDF)두 칸 중 원하는 쪽을 누르면 바뀌어요. 각각 PDF는 이미지마다 PDF 파일이 따로 만들어져 zip 하나로 받고(zip 안의 PDF 이름은 원본 이미지 이름을 그대로 쓰고, 아래 "파일 이름" 칸은 zip 파일 이름에만 쓰여요), 하나로 합치기는 지금 순서대로 이어붙인 PDF 한 개가 만들어져요.
공유변환이 끝나면 변환 버튼 옆에 나타나요. 방금 만든 파일을 카카오톡·메일 등으로 바로 보내요. 특히 아이폰에서는 PDF가 저장되지 않고 화면에 열리는 경우가 있어서, 그 화면에서 공유하면 파일과 함께 임시 주소(blob 주소)까지 같이 보내지고 그 주소는 받는 쪽에서 열리지 않아요 — 이 버튼을 쓰면 파일만 깔끔하게 가요. 공유 기능이 없는 브라우저에서는 버튼이 나타나지 않아요.
이미지 카드 버튼
↑ / ↓이미지를 앞/뒤로 한 칸씩 옮겨요. 카드를 직접 눌러 끌어서 옮길 수도 있어요(휴대폰에서는 손가락으로 똑같이 돼요).
↻이미지를 90도씩 회전해요. 여러 번 누르면 계속 돌아가요.
✕ 삭제이 이미지를 목록에서 지워요.
썸네일 우측 하단의 돋보기 — 이미지를 크게 확대해서 봐요. 열린 상태에서 ‹ › 버튼이나 방향키(←·→)로 다음·이전 이미지를 넘겨볼 수 있고, Esc나 "닫기"로 닫아요. 회전한 이미지는 회전된 모습 그대로 보여줘요.
