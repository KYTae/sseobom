PDF 워터마크·도장

PDF에 "대외비", "사본", 회사 이름 같은 글자 워터마크나 로고·도장 이미지를 얹어요. 글자만 적으면 둥근 도장이나 네모 도장도 바로 만들어 찍을 수 있어요. 위치는 9곳 중 고르거나 미리보기에서 끌어서 놓고, 크기·투명도·기울기와 바둑판 반복, 넣을 페이지(전체·범위·홀짝)를 정하면 오른쪽 미리보기에 바로 보여요. 원본 글자는 그대로 남고 워터마크만 위에 얹혀요.

PDF 올리기
드롭존PDF 한 개를 끌어다 놓거나 눌러서 고르세요. 올리면 첫 페이지가 미리보기에 나타나고, 페이지 수와 크기가 위에 보여요. 다른 PDF를 놓으면 설정은 그대로 두고 파일만 바뀌어요.
◀ ▶ 페이지미리보기의 페이지를 넘겨요. 워터마크를 넣지 않는 페이지는 흐리게 표시되고 "이 페이지에는 넣지 않아요"라고 알려줘요.
비밀번호·편집 제한 PDF열 때 비밀번호가 필요하거나 편집 제한(보안 설정)이 걸린 PDF는 넣을 수 없어요. 먼저 제한을 푼 PDF로 저장한 뒤 올려 주세요.
워터마크 종류
글자"대외비", "SAMPLE", 회사 이름 같은 글자를 적어요. 줄바꿈으로 여러 줄도 돼요. 글꼴(고딕·명조·고정폭)과 굵기, 색을 고를 수 있어요.
이미지·로고PNG·JPG·WEBP 이미지를 올려 얹어요. 배경이 투명한 PNG를 쓰면 로고만 깔끔하게 남아요.
도장 만들기이미지가 없어도 돼요. 글자만 적고 모양(원·네모)과 색을 고르면 도장이 만들어져요. "승인", "결재", "원본대조필"처럼 두 줄로 적어도 좋아요. 이미지 탭에서 도장 만들기를 누르세요.
위치 · 모양
위치 9곳가운데·모서리·가장자리 9곳 중 하나를 누르고, 여백으로 가장자리에서 얼마나 띄울지 정해요.
끌어서 놓기미리보기의 워터마크를 마우스나 손가락으로 끌어 원하는 자리에 놓을 수 있어요. 끌면 위치가 "직접 지정"으로 바뀌고, 모든 페이지에 같은 비율 자리로 들어가요.
크기 · 투명도 · 기울기크기는 페이지 너비 기준 %라 페이지 크기가 달라도 비슷하게 보여요. 투명도를 낮추면 본문이 비쳐 보이고, 기울기는 -90°~90°에요(-45°가 흔한 대각선).
바둑판 반복워터마크를 페이지 전체에 격자로 반복해요. 간격을 넓히거나 좁힐 수 있고, 반복을 켜면 위치는 쓰이지 않아요.
본문 위에 섞기켜면 워터마크가 본문 글자·그림과 겹치는 곳에서 곱하기 방식으로 섞여 글자를 덜 가려요(형광펜처럼). 끄면 워터마크가 본문을 그대로 덮어요. 스캔한 PDF 위에 도장을 찍을 때 켜두면 자연스러워요.
페이지 · 받기
넣을 페이지전체, 홀수, 짝수, 첫 페이지만, 또는 범위를 직접 적어요. 범위는 1-3, 5, 8-처럼 쉼표로 이어 적고, "8-"는 8쪽부터 끝까지예요.
PDF 받기지금 설정대로 워터마크를 넣은 새 PDF를 내려받아요. 원본 파일은 바뀌지 않고, 이름 뒤에 _워터마크가 붙어요. 페이지가 많으면 잠시 걸려요.
참고워터마크는 이미지로 얹혀서 어떤 글꼴·언어든 보이는 그대로 들어가요. 대신 PDF 안에서 글자로 검색·선택되지는 않아요. 워터마크를 지우기 어렵게 만드는 보안 기능은 아니에요.
