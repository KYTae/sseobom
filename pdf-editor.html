PDF 편집기

여러 PDF를 하나로 합치고, 원하는 페이지 범위로 나누고, 순서를 바꾸거나 회전하고, 필요없는 페이지는 지우세요. 페이지를 이미지로 저장할 수도 있어요.

파일 올리기 · 상단 버튼
+ 파일 추가지금 목록에 PDF 파일을 더 추가합니다.
전체 지우기올린 파일과 페이지를 모두 지우고 처음 화면으로 되돌립니다.
🔍 상세보기 / ← 파일 목록으로파일을 2개 이상 올리면 파일 카드 목록이 먼저 보이는데, 이 버튼으로 페이지 단위 화면과 파일 목록 화면을 오갈 수 있습니다.
페이지 카드 버튼
↑ / ↓페이지를 앞/뒤로 한 칸씩 옮깁니다. 카드를 직접 마우스로 눌러 끌어서 옮길 수도 있습니다(휴대폰에서는 손가락으로 동일하게 동작).
↻페이지를 90도씩 회전합니다. 여러 번 누르면 계속 돌아갑니다.
📐 A4비율여백 없이 페이지를 A4 비율(세로형이면 세로 A4, 가로형이면 가로 A4)로 꽉 채워 늘립니다. 원본 비율이 A4와 다르면 살짝 눌리거나 늘어날 수 있어요 — 확대 화면에서 "원본과 비교"로 확인할 수 있습니다. 이미 A4 비율인 페이지는 버튼이 자동으로 비활성화됩니다.
📥 이미지이 페이지 한 장을 고화질 PNG 이미지로 저장합니다.
✕ 삭제이 페이지를 목록에서 삭제합니다.
썸네일 우측 하단의 돋보기 — 페이지를 크게 확대해서 봅니다.
파일 카드 버튼 (파일 2개 이상일 때)
↑ / ↓파일 전체를 통째로 앞/뒤로 옮깁니다. 파일 안 페이지 순서는 그대로 유지됩니다.
🔍 상세보기이 파일의 페이지들을 페이지 단위 화면으로 열어서 순서변경·회전·삭제 등 세부 편집을 합니다.
✕ 파일 삭제이 파일 전체(안에 있는 모든 페이지)를 목록에서 삭제합니다.
다운로드
저장 파일명다운로드될 PDF 파일의 이름을 정합니다.
✂ 분할 저장"1-13, 14-30"처럼 페이지 범위를 직접 입력해서 여러 개의 PDF로 나눠 zip 파일 하나로 받습니다. 범위에 포함되지 않은 페이지(예: 13-24)는 어떤 파일에도 들어가지 않고 빠집니다.
🗜 압축 다운로드텍스트와 벡터는 그대로 두고, 사진처럼 용량이 큰 이미지만 다시 압축해서 전체 용량을 줄여 다운로드합니다. 사진이 적은 문서는 효과가 적을 수 있습니다.
PDF로 다운로드지금 화면에 보이는 순서·회전·A4비율·삭제 상태 그대로 하나의 PDF로 합쳐서 다운로드합니다.
그 밖에
💡 확대(돋보기)로 연 화면에서는 ‹ › 버튼이나 키보드 화살표로 다른 페이지로 넘어갈 수 있고, Esc나 배경 클릭·✕ 버튼으로 닫을 수 있습니다. 파일은 서버로 전송되지 않고 이 브라우저 안에서만 처리됩니다.
