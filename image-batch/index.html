이미지 일괄 처리

사진 여러 장을 한 번에 올리고 같은 규칙으로 처리해서 zip 하나로 받아요. 크기 조절, JPG·PNG·WEBP 변환과 용량 줄이기, 글자·로고 워터마크, 회전·반전, 파일 이름 바꾸기를 원하는 것만 켜서 조합할 수 있고, 규칙을 바꾸면 오른쪽 미리보기에 바로 반영돼요. 처리가 끝나면 사진마다 줄어든 용량과 바뀐 크기가 표시되고, 한 장씩 따로 받을 수도 있어요.

이미지 올리기
드롭존이미지를 여러 장 끌어다 놓거나 눌러서 고르세요. 폴더 안의 사진을 전부 선택해서 한 번에 놓아도 돼요. 이미 올린 뒤에도 페이지 어디에나 놓으면 뒤에 추가돼요.
파일 카드올린 사진이 카드로 쌓여요. 카드를 누르면 그 사진이 오른쪽 미리보기에 쓰이고, 카드 위 ✕로 목록에서 빼요. 같은 파일을 두 번 올리면 한 번만 들어가요.
모두 지우기올린 사진과 처리 결과를 전부 비워요. 규칙 설정은 그대로 남아요.
처리 규칙
스위치규칙마다 왼쪽 스위치를 켜야 적용돼요. 켜면 설정이 펼쳐지고, 접어도 헤더에 요약(예: 긴 변 1600px)이 남아서 무엇이 켜져 있는지 한눈에 보여요. 하나도 켜지 않으면 처리 버튼이 잠겨요.
크기 조절긴 변·가로·세로 픽셀이나 비율(%)로 맞춰요. 비율은 항상 유지돼요. "작은 사진은 키우지 않기"를 켜두면 기준보다 작은 사진은 그대로 둬요.
형식·용량JPG·PNG·WEBP로 바꾸거나 원본 형식을 유지해요. JPG·WEBP는 품질 슬라이더로 용량을 줄여요(PNG는 무손실이라 품질이 없어요). 투명한 사진을 JPG로 바꾸면 투명한 곳이 흰색이 돼요.
워터마크글자나 로고 이미지(PNG 권장)를 9곳 중 원하는 자리에 얹어요. 크기는 사진 기준 비율이라 사진마다 크기가 달라도 비슷하게 보여요.
회전·반전90°·180°·270° 회전과 좌우·상하 반전이에요. 크기 조절 뒤에 적용되니 "가로 1000px"로 맞춘 뒤 90° 돌리면 세로가 1000px이 돼요.
파일 이름앞·뒤에 글자를 붙이거나 번호를 매겨요. 원래 이름을 빼고 번호만 남길 수도 있어요. 아래에 처음 세 장의 결과 이름이 미리 보여요.
미리보기선택한 사진 한 장에 지금 규칙을 실제로 적용한 모습이에요(화면에 맞춰 줄여서 보여드리므로 용량은 여기서 알 수 없고, 처리 후 카드에서 실제 용량이 보여요). ◀ ▶로 다른 사진을 넘겨 볼 수 있어요.
처리 · 받기
N장 처리하기모든 사진에 규칙을 적용해요. 진행률이 보이고, 끝나면 카드마다 전 → 후 용량·크기와 감소율이 표시돼요.
zip으로 모두 받기처리된 사진을 zip 하나로 내려받아요. 카드의 작은 다운로드 버튼으로 한 장씩 따로 받을 수도 있어요. 이름이 겹치면 뒤에 (2), (3)이 붙어요.
규칙 바꿔서 다시처리 후 규칙을 바꾸면 결과가 지워지고 다시 처리할 수 있어요. 원본은 그대로라 몇 번이든 다시 해도 돼요.
