영상 편집 베타

영상 파일을 올리면 타임라인에서 원하는 부분만 남기거나 잘라내고, 여러 영상을 이어 붙일 수 있어요. 소리는 볼륨·음소거·페이드에 배경음악 덧입히기까지, 자막도 원하는 시간에 얹어서 MP4나 WEBM으로 내려받으세요. 설치도 서버 업로드도 없이 브라우저 안에서만 처리돼요.

자르기·트리밍·분할·이어 붙이기 · 속도 · 화면 비율·PIP·전환 · 색 보정·필터 · 볼륨·페이드·배경음악 · 자막 스타일 · MP4·WEBM · 해상도 선택
베타 · 아직 다듬는 중이에요 — 이상한 점은 홈의 의견 보내기로 알려주세요
파일은 서버에 업로드되지 않습니다 · 모든 처리는 이 브라우저 안에서 끝납니다 로그인·구독 필요 없음 · 몇 번을 다시 편집해도 완전 무료
처음 3분
1. 영상 올리기 → 2. 구간 잡기 → 3. 자르기 → 4. 내려받기영상을 올리면 아래에 타임라인이 생겨요. 눈금자를 드래그하거나 I/O 키로 구간을 잡고, "선택만 남기기"나 "선택 구간 삭제"를 누른 뒤 하단 바에서 MP4로 받으면 끝이에요. 잘못 눌렀으면 Ctrl+Z로 언제든 되돌려요.
타임라인 · 클립
클립 · 레인타임라인 위 사각형 하나가 클립이에요. 클릭하면 선택되고, 끌어서 원하는 시각·레인(V1, V2…)에 놓아요. 같은 레인에서 겹치게 놓으면 자동으로 위 레인으로 올라가고, 위 레인이 아래 레인을 덮어요(프리미어와 같은 방식). 양 끝을 끌면 시작·끝을 다듬는데, 줄어든 자리는 빈 여백으로 남아요.
빈틈 없애기잘라내거나 옮기면서 생긴 빈 시간(검은 화면)을 한 번에 없애고 뒤를 앞으로 당겨요. 여백을 일부러 두고 싶으면 누르지 않으면 돼요.
재생 위치에서 분할 (S)빨간 재생 위치를 기준으로 클립을 둘로 나눠요. 나눈 뒤 한쪽만 지우거나 순서를 바꿀 수 있어요.
선택만 남기기 / 선택 구간 지우기눈금자를 드래그해서 잡은 보라색 구간을 기준으로, 그 구간만 남기거나(앞으로 당겨져요) 그 구간을 지워요(자리는 여백으로 남고, 자막도 같이 지워져요). 여러 레인·클립에 걸쳐 있어도 한 번에 처리돼요.
+ 영상 추가 · 타임라인에 드롭버튼으로 올리면 맨 뒤에 이어 붙고, 파일을 타임라인 위에 바로 떨어뜨리면 그 시각·그 레인에 놓여요(영상은 영상 레인, MP3·WAV는 배경음악 레인). 해상도가 달라도 내보낼 때 첫 영상 크기에 맞춰 검은 여백으로 맞춰져요.
클립 속성 (속도 · 화면 · 전환 · 소리)클립을 선택하면 타임라인 아래에 속성이 나타나요. 속도 0.25~4배, 화면 맞춤/채움·크기·회전·불투명도, 시작 전환(디졸브·검은 화면·밀기·확대)과 끝 페이드, 색 보정, 볼륨·음소거·오디오 분리/지우기까지 여기서 해요.
미리보기에서 옮기기·키우기·자르기클립을 선택하면 미리보기 위에 파란 상자가 떠요. 상자 안을 끌면 위치, 모서리를 끌면 크기, 위쪽 동그라미로 회전(90°마다 자석), 네 변을 안쪽으로 끌면 그만큼 잘려요(크롭). 더블클릭하면 원래대로. 작은 화면 겹치기(PIP)는 위 레인에 올린 클립을 이렇게 줄이면 돼요.
색 (프리셋 · 밝기·대비·채도·색온도·비네트)클립마다 흑백·세피아·선명·빈티지·차분·시네마 프리셋을 고르고, 슬라이더로 밝기·대비·채도·색온도(파랑↔주황)·비네트(가장자리 어둡게)를 더해요. "모든 클립에 적용"을 누르면 영상 전체 톤이 한 번에 맞춰져요. 미리보기와 저장본에 똑같이 들어가요.
V1 소리 행 · 오디오 분리소리가 있는 영상은 영상 레인 아래에 "V1 소리" 행이 생겨요. 클릭하면 그 클립이 선택되고, 속성에서 음소거·"오디오 분리"(배경음악 레인으로 떼어내 따로 옮기고 자름)·"오디오 지우기"(영상만 남김)를 고를 수 있어요. 영상을 여러 개 겹칠 때 소리가 겹치면 여기서 정리해요.
+ 이미지PNG·JPG를 올리면 5초짜리 이미지 클립이 생겨요. 오른쪽 끝을 끌어 길이를 늘이고, 위 레인에 올려 로고·워터마크·스티커처럼 얹어요(투명 PNG도 돼요).
화면 탭 (비율 · 배경)16:9, 9:16(쇼츠·릴스), 1:1, 4:5 중에 고르면 완성본 크기가 바뀌어요. 남는 자리는 검정·흰색·원하는 색, 또는 영상을 확대해 흐리게 깐 블러 배경으로 채워요.
확대 (−/+)긴 영상에서 정밀하게 자를 때 타임라인을 확대해요. Ctrl+휠로도 돼요.
소리 · 자막
원본 소리영상에 들어 있던 소리의 전체 볼륨과 음소거, 처음·끝 페이드를 정해요. 목소리만 살짝 줄이고 배경음악을 얹는 식으로 써요.
+ 배경음악·목소리 추가MP3·WAV 같은 오디오 파일을 올리면 보라색 오디오 클립이 생겨요. 끌어서 위치를 옮기고 양 끝으로 잘라내며(반복 재생이 켜져 있으면 잘린 구간이 반복돼요), 선택한 뒤 "재생 위치에서 분할"로 나눌 수도 있어요. 볼륨·페이드는 소리 탭에서요.
+ 자막 추가 · 스타일문구(Enter로 여러 줄)·위치·크기·색에 글꼴(고딕·명조·손글씨·붓글씨·귀여운)·굵기·정렬·외곽선·그림자·배경 상자(색·불투명도)·등장/퇴장 페이드까지 정해요. 새 자막은 마지막 자막의 스타일을 따라가고, "이 스타일을 모든 자막에"로 한 번에 맞출 수 있어요. 타임라인의 주황 자막 클립을 끌어서 시각을 옮기고 양 끝으로 길이를 바꿔요(더블클릭 = 내용 편집). 영상에 직접 새겨지는 방식이라 어디서 열어도 똑같이 보여요.
오디오만 저장편집한 결과의 소리만 WAV 파일로 받아요. 영상은 빼고 소리만 필요할 때 써요.
내보내기
MP4 / WEBMMP4는 어디서나 열리는 기본 형식이에요. WEBM은 크롬·유튜브용으로 용량이 조금 작아요. 이 브라우저가 지원하지 않는 형식은 버튼이 비활성화돼요.
옵션 (해상도 · 화질)원본 크기 그대로 두거나 1080p·720p·480p로 줄이고, 화질(비트레이트)을 고르면 예상 용량이 바뀌어요. 짧은 영상을 카톡으로 보낼 땐 720p·보통 화질이 무난해요.
시간이 걸리는 이유모든 프레임을 이 컴퓨터에서 다시 그려 압축하기 때문에, 영상 길이와 해상도에 비례해 시간이 걸려요(보통 실제 길이의 절반~2배). 진행률이 보이고 언제든 취소할 수 있어요. 처리 중엔 이 탭을 닫지 마세요.
지원 브라우저 · 열 수 없는 영상크롬·엣지·최신 사파리에서 동작해요(WebCodecs라는 브라우저 기능이 필요해요). MKV·AVI처럼 브라우저가 재생하지 못하는 파일이나 HEVC(H.265)를 지원하지 않는 기기에서는 열 수 없어요 — MP4(H.264)·MOV·WEBM은 대부분 잘 돼요.
